# Pace — Fitness & Habit Tracker

A vanilla HTML/CSS/JS fitness and habit tracker built for the Centre of Software Intelligence probation task.

## Features
- Daily task manager with drag-and-drop
- Habit tracker with a GitHub-style completion graph
- Water, sleep and calorie logging
- Pomodoro timer linked to tasks
- Daily motivational quote (public API) with a saved-quotes CRUD
- Weekly summary dashboard
- All data persisted in localStorage — no backend

## Run it
Just open `index.html` in a browser. No build step, no dependencies.
